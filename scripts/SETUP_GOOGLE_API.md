# Google Places API セットアップ手順

全店舗の座標を建物単位で精密化するためのAPIキー取得手順。**所要時間：10分**。

---

## ステップ1：Google Cloud Console にアクセス

https://console.cloud.google.com/

Googleアカウント（後藤さんの普段のGmailでOK）でログイン。

---

## ステップ2：プロジェクト作成

1. 画面上部の「プロジェクト選択」プルダウン → 「新しいプロジェクト」
2. プロジェクト名：`fukuoka-connect-maps`（任意）
3. 「作成」

---

## ステップ3：請求アカウント設定（カード登録）

1. 左メニュー → 「お支払い」
2. 「請求先アカウントをリンク」→「新規作成」
3. クレジットカード情報を入力
   - **無料枠$200/月あり**。75店舗の更新は約$1.3なので**ほぼ確実に無料**
   - $200超えそうになると自動停止する設定にしておくと安心

---

## ステップ4：Places API（New）を有効化

1. 左メニュー → 「APIとサービス」→「ライブラリ」
2. 検索ボックスに `Places API (New)` と入力
3. 「Places API (New)」をクリック → 「有効にする」

---

## ステップ5：APIキー作成

1. 左メニュー → 「APIとサービス」→「認証情報」
2. 上部「+ 認証情報を作成」→「APIキー」
3. キー（`AIzaSy...` で始まる文字列）が表示される → **コピー**

### （任意）キー制限の設定（推奨）
作成後の「キーを編集」から：
- 「APIの制限」→「キーを制限」→「Places API (New)」のみチェック
- これで万一漏れても他のAPIで悪用されない

---

## ステップ6：私に送る

APIキー（`AIzaSy...`）を私に送ってください。

→ こちらで実行：
```bash
GOOGLE_API_KEY=AIzaSy... python3 scripts/geocode_with_google.py --dry-run
# 確認OKなら本実行
GOOGLE_API_KEY=AIzaSy... python3 scripts/geocode_with_google.py
```

全店舗（cid確定の14店を除く61店）の座標を建物単位で取得・更新→push します。

---

## コスト見込み

- Places API (New) Text Search: $0.017/リクエスト
- 75店舗 × 1回 = **約 $1.28 ≒ 約200円**
- ただし**月$200の無料クレジット**があるので**実質0円**
- 今後の新規追加時も同スクリプトで自動精密化可能
